- Ассистент: GitHub Copilot

## Краткий контекст проекта

- Репозиторий: purple-avito-hackaton
- Задача: автоматическое выделение самостоятельных услуг и генерация черновиков объявлений в категории «Ремонт и отделка».
- Основная идея решения: гибрид из TF-IDF (n-граммы) + нейросеть (Transformer + обучаемые эмбеддинги микрокатегорий + softmax).

## Хронология диалога

### 1) Запрос пользователя

Пользователь попросил:

1. Реализовать TF-IDF с биграммами/триграммами и поиск по ключевым фразам микрокатегорий для отсева нерелевантных.
2. Сделать softmax-модель: текст кодируется трансформером, микрокатегории — обучаемыми эмбеддингами, на выходе распределение вероятностей создания черновиков.

### 2) Что сделал ассистент

- Проверил структуру репозитория и обнаружил пустой файл model/model.py.
- Реализовал в model/model.py:
    - dataclass-структуры для сущностей задачи;
    - класс TfidfMicroCategoryRetriever (поиск кандидатов микрокатегорий по ключевым фразам, ngram_range=(2,3));
    - класс TransformerSoftmaxSplitModel (Transformer encoder + embedding-таблица микрокатегорий + softmax по кандидатам);
    - класс DraftSplitPipeline (сквозной пайплайн predict/train_step);
    - to_response_json для приведения результата к формату хакатона.
- Исправил issues по анализатору кода, чтобы файл проходил проверку.
